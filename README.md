## 🚀 Features
- 🎨 **Smooth Animations** - Framer Motion for engaging transitions
- 📱 **Fully Responsive** - Perfect on mobile, tablet, desktop
- ⌨️ **Interactive Elements** - Tabbed skills/certificates, project filters
- 📥 **CV Download** - Direct PDF download
- 🔍 **Project Showcase** - 8+ projects with screenshots, tech stacks, live links
- 💫 **Typed.js Hero** - Dynamic role titles
- ⚡ **Fast & Optimized** - Vite HMR + Tailwind JIT

## 🎯 Quick Start
```bash
# Navigate to app directory
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) 🎉

## 🔨 Build for Production
```bash
cd portfolio
npm run build  # Outputs to dist/
npm run preview  # Local preview of build
```

Deploy to:
- [Vercel](https://vercel.com) (recommended)
- [Netlify](https://netlify.com)
- [GitHub Pages](https://pages.github.com)
